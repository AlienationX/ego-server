# 每日精选壁纸推广素材与爆款文案生成技能

本技能专门用于运营小红书和微信公众号壁纸账号。它解决了两个核心痛点：
1. **壁纸选品不重样**：支持加权随机抽样与历史排重（自动排除近 14 天已发壁纸），支持按“每日限免”、“分类”（如可爱萌宠、自然风光）或“主题标签”（如 AI美女、赛博朋克、治愈系）精准选品。
2. **文案千人千面、极具网感**：摆脱传统死板的固定模板，由大模型根据当天实际选中的 17 张壁纸的画面细节与标签，原创独一无二的小红书与微信爆款文案。

---

## 执行流程

### 第一步：明确选品模式与参数

与用户确认或根据用户指令选择模式：
- **每日限免模式**：`--mode daily_free`（默认，选自每日限免与广告激励池）
- **分类模式**：`--mode category --category <分类名称>`（如 `AI美图`, `可爱萌宠`, `自然风光`, `明星美女`, `动漫二次元` 等，可用 `--list-categories` 查看所有分类）
- **主题/标签模式**：`--mode theme --theme <主题关键词>`（如 `AI美女`, `治愈`, `黑丝`, `极简`, `机甲` 等，可跨分类按标签与描述检索）

### 第二步：预览选品清单（获取当日壁纸细节）

在渲染大图前，先执行快速预览，获取当日抽中的 17 款壁纸的 ID、标题与标签：
```bash
# 工作目录必须在 ego/ 下，使用 .venv Python
cd /Users/tangzy/code/python/ego-server/ego
../.venv/bin/python manage.py generate_daily_promo --preview-walls --mode <mode> [--category <cat>] [--theme <theme>]
```
返回的 JSON 清单包含了这 17 款壁纸的具体特征，用于下一步指导大模型构思针对性文案。

### 第三步：大模型动态创作原创爆款文案

根据实际获取的 17 款壁纸特征，发挥大模型最高水准的文案创作能力，撰写以下 4 部分内容：

1. **封面大标（4~8个汉字）**：
   - 极具视觉冲击力与网感。
   - 例如：`黑丝冷艳 · 质感锁屏`、`奶油萌猫 · 治愈日常`、`雨夜赛博 · 微光沉浸`。
2. **小红书爆款标题（提供 1 个主标题 + 2 个备选）**：
   - 带有情绪共鸣词、标点与 emoji。
   - 例如：`美到失语！18款高级感冷艳锁屏，谁看谁迷糊🔥`。
3. **小红书正文（约 150~250 字，精炼高级）**：
   - **黄金前 3 秒共鸣金句**（吸引停留）。
   - **重点壁纸视觉亮点点评**（结合具体某几张壁纸的画面特征，如“第 1 张银装素裹的北国雾凇、第 2 张治愈系慢调插画”）。
   - **机型与画质表述**：统一使用【iPhone】，不强调 iPhone 17。
   - **注意**：第 18 张尾图已自带完整的小程序直达步骤与【体验码】说明，**正文无需重复“想要原图评论区留言/私信发体验码”等冗余话术**，保持文字轻盈纯粹。
   - **互动与高热度 Hashtag 标签**（引导互动“最心动哪一款” + 5~8 个热门标签）。
4. **微信公众号贴图配文（约 100~150 字）**：
   - 专为公众号【图片/贴图消息】打造，行文优美流畅、段落精致、排版留白。
   - 统一使用【iPhone】，第 18 张图已有说明，文末无需再写冗长获取指引。

### 第四步：写入文案并一键渲染生成物料包

将生成的文案分别存入 scratch 目录下的临时文件中：
- 小红书正文：`<appDataDir>/brain/<conversation-id>/scratch/xhs_body.txt`
- 微信配文：`<appDataDir>/brain/<conversation-id>/scratch/wechat_post.txt`

执行全流程生成命令（默认无时钟、无底部小组件，纯净展示壁纸原貌）：
```bash
cd /Users/tangzy/code/python/ego-server/ego
../.venv/bin/python manage.py generate_daily_promo \
  --mode <mode> \
  [--category "<category>"] \
  [--theme "<theme>"] \
  --custom-title "<封面主标题>" \
  --custom-xhs-title "<小红书主标题>" \
  --custom-xhs-body-file "<小红书正文临时文件绝对路径>" \
  --custom-wechat-file "<微信配文临时文件绝对路径>"
```

### 第五步：直观交付成果

执行完毕后，向用户汇报并提供：
1. **图片预览**：嵌入封面（`01_cover.png`）、代表性内页展示图（如 `02_wall_#xxx.png`、`03_wall_#xxx.png`）和尾图（`18_guide_tail.png`）。
2. **文案一键复制区**：
   - 小红书完整文案（`xhs_post.txt`，含多备选标题、正文、标签）。
   - 微信贴图专用配文（`wechat_post.txt`）。
3. **素材包路径**：告知用户输出文件夹（`ego/media/promo_output/YYYY-MM-DD`），包含 18 张高精无损真机图与文字说明。
